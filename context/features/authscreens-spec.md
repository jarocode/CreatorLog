# Auth Screens Spec

## Overview

This is for the Auth screens which includes: Sign in, Sign up and Forgot password screens . Use the screenshot referenced in this file for how they should should look.

## Requirements

- Implement the sign-in screen ui EXACTLY (pixel-perfect) as it is shown in @context/screenshots/sign-in-screen.png
- Implement the sign-up screen ui EXACTLY (pixel-perfect) as it is shown in @context/screenshots/sign-up-screen.png
- Implement the forgot-password screen ui EXACTLY (pixel-perfect) as it is shown in @context/screenshots/forgot-password-screen.png
- Note that the ui shown in @context/screenshots/reset-password.png is also part of the forgot-password screen ui, and it should be displayed when the user clicks the 'Send reset link' button, while the 'Back to signin' should navigate back to the sign-in screen
- Ensure for all 3 screens, you must implement Dark mode and light state as shown in the screenshots, follow the coding standards at @context/coding-standards.md and also maintain the project structure in @context/project-overview.md
