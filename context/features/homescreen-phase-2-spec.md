# Homescreen Dashboard UI Phase 2 Spec

## Overview

This is phase 2 of 2 for the homescreen UI layout. Use the screenshot referenced below for how it should look.

## Requirements for phase 2

- Implement the dark mode versions of the homescreen ui (use the screenshots in references)
- For interactivity, Add a toggle button to the settings screen to toggle between light mode (light mode is already implemented) and dark mode
- Create a global theme or config that would ensure the toggle between light/dark modes for future screens or features that would we implemented.
- Implement the Milestone celebration pop-up shown in context/screenshots/dashboard-streak-narrative.png (for both light and darkmode), for now clicking on any of the social media cards should render/unrender it.
- The settings icon at the top right of the homescreen should navigate to the settings screen when clicked
  -Your designs should be exactly as shown in the screenshots
- you must follow the project structure using section 10 in @context/project-overview.md
